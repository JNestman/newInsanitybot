# insanitybot

newInsanitybot is a project I designed from the ground up to compete in Starcraft: Brood War AI competitions utilizing BWAPI. The original insanitybot project was a fork of @JayScott's steamhammer focused on Terran play.
After some time I decided I wanted to build from the ground up and thus this project was born. The goal of insanitybot is to find interesting strategies and paths to win including off meta technology use.

## Features
- A variety of build orders including two base mechanized play, two base bio play, and various all in strategies.
- Basic game tracking utilizing read and write files to weigh more successful build orders against specific opponents, on specific maps, at specific starting locations.
- Liberal use of the medic ability Optical Flare.
- Building placement logic to stack/group buildings in intelligent ways and save on space within the main base.
- Squad based unit movement, attack orders, and grouping.
